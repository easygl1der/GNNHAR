\section{Design}
This verification run implements a Zhang-style rolling forecast design. For each forecast origin, the asset graph is recomputed from pre-origin returns using Graphical Lasso cross-validation. The forecasting block contains 22 trading days, and neural models use a pre-origin validation window. The target is 30-day close-to-close realized volatility; the IV extension adds 30-day mean implied volatility HAR lags.
The model set is HAR, GHAR, GHAR2H, GHAR3H, HAR+IV, GHAR+IV, GHAR2H+IV, GHAR3H+IV, and GNNHAR1L/2L/3L with and without IV. GHAR2H and GHAR3H are linear multi-hop graph feature extensions; GNNHAR2L and GNNHAR3L are nonlinear multi-layer message passing models.
\section{Run Scope}
This is a local two-block verification run, not the final Colab long run. It is useful for checking data pairing, graph construction, model inclusion, and preliminary scale direction. A longer Colab run should increase the number of rolling blocks and neural epochs.

\section{Interpretation}
In this verification run, the graph-only GHAR gain is small. For S\&P100 it is slightly negative by QLIKE, while for S\&P500 it is positive but only about 0.35\%. The IV channel is much stronger and scales up: IV gain in GHAR is about 1.88\% for S\&P100 and 5.25\% for S\&P500. Linear multi-hop GHAR does not dominate one-hop GHAR in these two blocks; GHAR+IV remains the best QLIKE model in both universes. The neural GNNHAR models underperform in this short local run, so their ranking should not be treated as final without the longer Colab run and broader tuning.
